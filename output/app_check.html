Before you start
  1. Setup (once): cd hw4 && python3 -m venv .venv && source .venv/bin/activate && pip install -r requirements.txt && cp .env.example .env, then put your keys in .env and unzip data.zip into hw4/.
  2. Backend: cd backend && uvicorn main:app --reload (check http://127.0.0.1:8000/api/health shows "portkey_key_set": true).
  3. Frontend: cd frontend && npm install && npm run dev, then open the URL above.
  4. Tool tests (optional): cd backend && python test_tools.py && python test_audit.py (expect 14 and 6 passed).
  5. Logged-in checks write to data/campus_customs.db (your account and chat history). Use a test account if you want to keep real data clean.
